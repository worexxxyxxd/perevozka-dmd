# PEREVOZKA_DMD — сайт грузоперевозок

Одностраничный сайт грузоперевозок и переездов по Москве, Московской области и всей России.

- 3D-сцена на первом экране (three.js): Газель с рекламой на борту едет по ночной дороге
- 3D-иллюстрации видов погрузки (задняя, боковая, верхняя) на чистом CSS
- Заявка с сайта отправляется в WhatsApp
- Адаптивная вёрстка для телефонов

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка и тексты |
| `style.css` | Оформление |
| `script.js` | Меню, форма заявки, 3D-эффекты карточек |
| `hero3d.js` | 3D-сцена с Газелью |
| `img/` | Фотографии |

## Как открыть

Откройте `index.html` в браузере. Для 3D-сцены нужен интернет — библиотека three.js подгружается с CDN.

Телефон для WhatsApp меняется в начале `script.js` (`CONFIG.phoneWa`).
